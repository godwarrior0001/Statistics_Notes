# Day 6: Hypothesis Testing

## 1. Logic of Testing
* **Null Hypothesis (H0)**: The default "no effect" claim[span_43](start_span)[span_43](end_span).
* **Alternative Hypothesis (H1)**: The claim we seek evidence for[span_44](start_span)[span_44](end_span).

## 2. Errors & Decision Rule
* **Type I Error ($\alpha$)**: False positive (rejecting a true H0)[span_45](start_span)[span_45](end_span).
* **Type II Error ($\beta$)**: False negative (failing to reject a false H0)[span_46](start_span)[span_46](end_span).
* **Decision Rule**: Compare the p-value to the significance level $\alpha$ (commonly $0.05$); reject H0 if $p \le \alpha$[span_47](start_span)[span_47](end_span).

## Common Tests
* One-sample/Two-sample t-tests, Chi-square test for categorical association, and ANOVA for comparing $\ge 3$ group means[span_48](start_span)[span_48](end_span).
